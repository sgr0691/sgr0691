## What I'm Building

### Shared workspace for humans and agents

**Campfire** is my main independent product bet.

The thesis is simple: one agent in one session is manageable. A team of agents across private terminals is not — unless the work has a **durable place** to live.

Campfire is not an orchestrator. It is a workspace for:

* goals
* sessions
* decisions
* findings
* history

So the next person or agent is not starting from nothing.

Site: [boringinfra.company/campfire](https://boringinfra.company/campfire)  
GitHub: [github.com/BoringInfraCo/Campfire](https://github.com/BoringInfraCo/Campfire)

### Root

A safer, more inspectable package and environment workflow for developers and coding agents.

Root is built around the idea that installs and environments should be:

* reproducible
* reversible
* inspectable
* agent-friendly
* powered by Nix without making users become Nix experts

Repo: [github.com/BoringInfraCo/Root](https://github.com/BoringInfraCo/Root)

## My Product Philosophy

I believe AI products should make people feel more capable, not less involved.

The best tools do not remove the human. They give the human:

* more context
* better timing
* clearer tradeoffs
* safer defaults
* faster paths from idea to reality

I like building products that feel practical, grounded, and useful before they feel magical.

Design + engineering is not a contradiction anymore. It is the baseline.
